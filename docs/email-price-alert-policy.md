# 이메일 가격 알림 정책

확인일: 2026-08-18

## 발송 서비스 전제 조건

가격 알림은 거래성 이메일로 발송한다. 가신은 **Gmail SMTP만 사용**하며, Gmail 계정의 일반 비밀번호가 아닌 2단계 인증 후 발급한 16자리 앱 비밀번호로 인증한다. Resend API와 Resend 키는 사용하지 않는다.

## 가신 알림 규칙

- 사용자가 상품을 찜하면 해당 상품의 가격 알림 수신에 동의한 것으로 기록한다.
- 사용자가 직접 찜을 해제하면 해당 상품의 동의는 철회되고 이후 알림을 보내지 않는다.
- 기준 가격은 해당 상품의 최근 24시간 가격 이력 중 최저가다.
- 현재가가 그 24시간 최저가와 같거나 낮을 때, 같은 찜 등록 주기에는 상품별로 한 번만 발송한다.
- 발송 기록을 영속 저장해 정기 작업 재시도와 중복 실행에서도 중복 이메일이 발송되지 않게 한다.
- 이메일에는 상품명·현재가·24시간 최저가·확인 시각·저장된 쿠팡 파트너스 링크·찜 해제 링크를 포함한다.
- 발송 직전에 찜 등록 주기별 영속 이력 레코드를 먼저 확보한다. 정기 작업이 재시도되거나 중복 실행돼도 해당 찜 등록 주기에는 SMTP를 다시 호출하지 않는다.
- SMTP 전송 실패도 영속 기록으로 남긴다. 이 정책은 불확실한 네트워크 상태에서 동일 알림이 여러 번 도착하는 일을 막기 위한 **at-most-once 발송** 원칙이다.
- 메일의 해제 링크는 특정 찜 레코드만 대상으로 하는 서명 토큰을 사용한다. 이미 해제한 뒤 다시 찜한 새 등록 주기에는 이전 메일의 링크가 영향을 주지 않는다.
