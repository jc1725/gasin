# 네이버 프로그램 검토와 안전한 제품 후보 추가 방안

작성일: 2026-08-15

## 결론

첨부된 프로그램은 **가신의 제품 탐색용 네이버 API 클라이언트가 아니다.** 네이버 커머스 API로 본인 스마트스토어의 채널 상품을 조회·수정하고, 별도의 브라우저 자동화로 네이버 쇼핑 카탈로그 화면에서 판매자·가격을 읽어 경쟁 가격을 계산한 뒤 스토어 판매가를 바꾸는 도구다.

따라서 이 프로그램을 가신에 연결해 쿠팡 상품을 자동으로 찾거나 가격을 갱신하는 방식은 채택하지 않는다. 특히 브라우저 자동화 기반 페이지 추출은 가신의 승인 API 전용 수집 정책과 맞지 않으며, 쿠팡 Search API 호출을 대체하는 안전한 상품 식별 근거도 제공하지 않는다.

> 현재 쿠팡 Search API 보호 레코드는 `2026-08-15T17:06:50Z`까지의 차단 상태다. 해제 전에는 가격·GoldBox 작업과 새 딥링크 생성을 재개하지 않는다.

## 첨부 프로그램의 실제 동작

| 구성 | 확인된 동작 | 가신에 대한 판단 |
| --- | --- | --- |
| 네이버 커머스 API | 본인 스토어의 채널 상품을 조회하고 판매가를 수정 | 본인 스토어 관리 용도로만 제한 가능 |
| 브라우저 자동화 | 로컬 Chrome의 네이버 쇼핑 카탈로그 화면을 열어 판매자·가격 텍스트를 추출 | 가신에 통합하지 않음 |
| 가격 계산 | 경쟁 판매자 총액을 기준으로 본인 판매가를 계산하고 10분 주기로 갱신 | 쿠팡 가격 추적·제품 추가와 분리 |
| 제품 목록 | 코드 내 정적 `PRODUCT_LIST`에 본인 스토어 상품번호와 카탈로그 ID 보관 | CSV 또는 Drive 기반 후보 가져오기 구조로만 참고 |

## 네이버 공식 API 사용 가능 범위

네이버 커머스 API는 스마트스토어의 주요 기능을 HTTP API로 제공하는 서비스이며, 이용을 위해 커머스 API 센터 가입·애플리케이션 등록·권한 획득이 필요하다.[1] 즉, 첨부 프로그램의 인증 방식은 **본인 스마트스토어 상품 운영**에 맞는 방식이지, 외부 시장의 모든 상품을 검색하는 공개 카탈로그 API는 아니다.

한편 네이버 개발자센터 공지에 따르면 쇼핑 검색 API는 2026-07-31에 종료되며, API HUB를 포함한 별도의 대체 API가 제공되지 않는다.[2] 현재 날짜가 이 종료일 이후이므로, 새 가신 기능의 제품 후보 수집원으로 네이버 쇼핑 검색 API를 채택해서는 안 된다.

## 쿠팡 정책을 보전하는 제품 목록 추가 경로

| 추가 경로 | 외부 쿠팡 호출 | 실제 상품 등록 시점 | 쿠팡 정책 위험 | 권장 여부 |
| --- | --- | --- | --- | --- |
| GoldBox 공식 응답 | GoldBox 승인 API만 사용 | 수집 결과를 바로 추적 목록에 저장 | 낮음. 기존 전역 분당 예산 적용 | 권장 |
| 사용자가 쿠팡 URL 직접 입력 | 등록 시 0회 | `waiting` 후보로 보관하고 보호 해제 뒤 승인 API 예산에서 처리 | 낮음 | 권장 |
| CSV 또는 개인 Drive 후보 가져오기 | 가져오기 시 0회 | 후보 보관함에 저장하고 사용자가 검토·승인 | 낮음 | 권장 |
| 기존 DB 검색·찜·최근 조회 재추적 | 캐시 우선, 필요 시 기존 엄격 예산 적용 | 이미 저장된 SKU만 갱신 | 낮음 | 권장 |
| 본인 스마트스토어 상품 목록 | 네이버 커머스 API만 사용 | 이름·옵션을 후보로만 보관, 쿠팡 매칭은 사용자 검토 후 | 낮음 | 조건부 권장 |
| 네이버 쇼핑 화면 자동 추출 | 네이버 화면 자동화 | 경쟁 가격으로 자동 판단 | 서비스 정책·유지보수 위험, 쿠팡 매칭 근거 부적합 | 비권장 |

## 권장 구현: 후보 보관함

다음 기능은 쿠팡 Search API를 호출하지 않고 제품을 추가할 수 있다.

1. 사용자는 CSV 또는 개인 Google Drive 파일에 `상품명`, `용량/수량`, `옵션명`, `원본 URL`, `메모`를 입력한다.
2. 가신은 해당 행을 **후보 보관함**에 저장한다. 이 단계에서는 쿠팡 가격, 딥링크, SKU를 만들지 않고 외부 API도 호출하지 않는다.
3. 사용자가 쿠팡 상품 URL을 직접 확인해 연결하면 후보는 현재의 수동 링크 대기 흐름으로 이동한다.
4. 보호 해제 이후에도 후보를 한 번에 처리하지 않는다. 승인된 API의 전역 분당 예산·Search API 시간당 예산·기존 쿨다운을 통과한 항목만 처리하며, 정확 SKU가 확인되지 않으면 `waiting` 상태를 유지한다.
5. 딥링크는 정확 SKU가 확정된 뒤 한 번만 생성해 저장하고 재사용한다.

이 설계에서 네이버 커머스 API는 사용자의 **자체 스마트스토어 상품명·옵션을 후보 파일로 내보내는 보조 수단**으로만 쓸 수 있다. 네이버 데이터로 쿠팡 상품을 자동 매칭하거나, 화면 자동화로 경쟁 가격을 추출해 쿠팡 가격 추적을 보완하지 않는다.

## 즉시 보안 조치

첨부 코드에는 클라이언트 식별자와 비밀값으로 보이는 문자열이 소스 기본값으로 포함돼 있다. 채팅에 노출된 값은 노출된 것으로 간주해야 한다. 네이버 커머스 API 센터에서 해당 자격 증명을 폐기 또는 재발급하고, 코드에서는 기본값을 제거한 뒤 배포 환경의 비밀 환경 변수로만 제공해야 한다. 이 값은 가신 저장소, 로그, 문서, 브라우저 코드에 넣지 않는다.
