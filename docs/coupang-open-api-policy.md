# 쿠팡 Open API 호출 정책 참고 기록

확인일: 2026-08-18

## 공식 문서 확인 내용

- [Coupang Open API Rate Limit Policy](https://developers.coupang.com/en/notices/introduction-of-open-api-rate-limit-policy)는 전체 Coupang API에 호출 제한이 적용되며, 기준을 초과하면 즉시 차단 및 `429 Too Many Requests`가 발생할 수 있다고 안내한다. 기준은 시스템과 vendor ID에 따라 달라질 수 있다.
- [Coupang Open API Getting Started](https://developers.coupang.com/en/getting-started/coupang-open-api)는 `productId` 아래에 item과 `vendorItemId` 옵션 단위가 존재하며, `vendorItemId`가 가장 작은 옵션 식별 단위라고 설명한다.
- 파트너스 도움말 URL은 동적 렌더링으로 자동 추출이 되지 않았으나, 운영자 요청에 따라 `/products/search`의 분당 최대 50회·최대 10개 결과 기준을 적용한다.

## 가신 운영 정책

- 쿠팡 공식 API의 전체 호출은 검색·가격 추적·GoldBox·딥링크를 합산해 분당 46회 이하로 제한한다.
- 상품 검색 전용 예산은 분당 45회 이하로 제한하며, 실제 검색 결과는 최대 10개로 고정한다.
- 가격 추적은 마지막 확인이 가장 오래된 상품을 우선으로 하며, 하루 한 번 30분 지연된 일정으로 실행한다.

## 검색 위젯 확인 기록

제공된 `https://coupa.ng/coQgCL` 주소는 쿠팡 CDN의 검색 입력 위젯을 렌더링한다. 위젯 구성 URL에는 `link.coupang.com/re/AFFSRP?pageKey={keywords}` 제휴 검색 이동 주소가 포함되어 있으며, 입력한 검색어는 쿠팡 제휴 검색 결과 페이지로 전달된다. 따라서 이 위젯은 가신 서버에 상품 데이터나 가격 정보를 반환하는 API가 아니며, 호스트 페이지가 검색 결과를 읽거나 가신 목록으로 재사용할 수 없다. 위젯 검색 이동 자체는 가신의 쿠팡 Open API 호출 예산을 사용하지 않는다.

## 홈 인기 상품 데이터 범위

2026-08-18에 확인한 쿠팡 파트너스 공식 API 문서는 `GET /products/bestcategories/{categoryId}`를 **카테고리 별 베스트 상품** 조회로 제공하며, `GET /products/goldbox`는 골드박스 특가 상품 상세 조회로 제공한다고 명시한다. 반면 공개 응답으로 개별 상품의 실제 구매 수·판매량을 제공한다고는 명시하지 않는다. 따라서 가신은 구매량 수치를 추정하거나 임의의 판매량 순위를 만들지 않는다. 홈은 승인된 `bestcategories` 데이터가 저장된 경우 이를 `카테고리 베스트 상품`으로 표시하고, 준비 전에는 공식 GoldBox 특가 상품을 대체 목록으로 표시한다.

카테고리 베스트 API는 예시 URL `.../products/bestcategories/1001?limit=50`과 함께 1001 여성패션, 1002 남성패션, 1010 뷰티, 1011 출산/유아동, 1012 식품, 1013 주방용품, 1014 생활용품, 1015 홈인테리어, 1016 가전디지털, 1017 스포츠/레저, 1018 자동차용품, 1019 도서/음반/DVD, 1020 완구/취미, 1021 문구/오피스, 1024 헬스/건강식품, 1025 국내여행, 1026 해외여행, 1029 반려동물용품, 1030 유아동패션을 명시한다. 상품명·가격·상품 URL·상품 이미지 등은 제공하지만 구매량 수치는 포함하지 않는다. 이 API의 호출도 가신 전역 쿠팡 API 분당 46회 예산에 포함한다.

## 딥링크 변환과 검색 응답의 제휴 링크

공식 파트너스 API 문서의 `POST /deeplink`는 쿠팡 URL을 회원 트래킹 코드가 포함된 단축 URL로 변환한다. 반면 공식 상품 검색·카테고리 베스트 응답의 `productUrl` 예시는 이미 `link.coupang.com/re/AFFSDP` 형태의 제휴 링크를 제공한다. 따라서 이 형식의 URL은 딥링크 API를 다시 호출하지 않고 즉시 저장·재사용해야 하며, 전역 API 호출 예산을 소모하지 않는다.

공개 문서에는 검색 API의 분당 50회 한도와 카테고리 베스트의 400·403·429 오류 응답이 명시되어 있다. 딥링크 API는 URL 변환 기능을 문서화하지만 페이지에 별도의 숫자형 분당 한도를 명시하지 않는다. 가신은 429 또는 보호 상태가 발생하면 추가 호출을 중단하고 저장된 링크만 사용한다.

## 찜한 상품 가격 알림 전달 정책

현재 가신은 찜한 상품의 최저가 근접·도달을 이메일, 푸시, 문자 또는 외부 메신저로 자동 발송하지 않는다. 따라서 사용자의 이메일 주소로 가격 알림이 전송된 적도 없으며, 가격 확인은 서비스 내 찜 목록·상품 상세의 현재가와 최저가 표시를 통해 이뤄진다.

향후 이메일 알림은 사용자의 명시적 수신 동의, 알림 기준(최저가 도달 또는 사용자별 목표가), 중복 발송 방지, 수신 거부와 이메일 발송 서비스의 별도 자격 증명이 갖춰진 뒤에만 추가한다. 프로젝트 소유자 알림 도구는 운영자용이므로 일반 사용자 가격 알림 채널로 사용하지 않는다.
