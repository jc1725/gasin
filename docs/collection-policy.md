# 가신 데이터 수집 정책

가신은 쿠팡의 승인된 파트너스 API와 서비스 약관 범위에서만 상품 정보를 수집합니다. 서비스는 접근 통제 우회, 비공개 내부 엔드포인트 호출, 프록시 회전 또는 자동화 탐지 회피 기법을 사용하지 않습니다. 승인된 응답에서도 상품 식별자, 이름, 가격, 이미지 URL, 제휴 URL, 카테고리, 배송 플래그처럼 가격 추적과 표시에 필요한 최소 필드만 정규화하여 저장합니다.

상품 검색은 DB 캐시와 기존 가격 추적 목록을 우선 사용합니다. 외부 Search API가 필요한 경우에는 전역 시간당 8회 예산과 요청 사이 8분 쿨다운을 적용하며, 403 응답 또는 운영자가 설정한 보호 기간에는 모든 외부 쿠팡 요청을 중단합니다. 보호 기간에는 사용자에게 저장된 결과만 제공하고 신규 링크는 대기 상태로 등록합니다.

가격 이력은 사용자가 찜한 상품, 수동으로 등록한 링크, GoldBox로 수집된 상품처럼 실제 추적 수요가 확인된 항목을 중심으로 관리합니다. GoldBox API가 승인된 범위에서 해당 상품을 다시 제공하면 가격 이력을 갱신하고, 수동 링크의 식별자가 일치하면 대기 항목을 활성화합니다. Search API로 수집된 상품은 쿼터 보호 정책상 정기 재검색하지 않습니다.

수동 링크는 쿠팡 도메인과 안전한 상품 식별자가 확인된 경우에만 등록합니다. 등록 후 승인된 검색 결과에서 일치 상품을 아직 찾지 못했거나 Search API가 보호 모드인 경우에는 `waiting` 상태와 재시도 사유를 유지합니다. 이러한 일시적·정상적 미발견 사유로 자동 `rejected` 전환하지 않으며, 다음 안전한 조회 기회에 하나씩 재처리합니다. `rejected`는 향후 명시적인 영구 무효 판정 기준을 도입했을 때만 사용합니다.

상품 상세를 최근 조회하면 저우선 상품은 일반 우선순위로 승격합니다. 그러나 현재 1시간 가격 갱신의 대량 확인 대상은 승인된 GoldBox 응답에서 확인 가능한 `goldbox` 출처 상품으로 한정됩니다. 따라서 최근 조회한 `search` 출처 상품은 검색 API를 매시간 재호출하지 않으며, DB 캐시·사용자 검색·수동 링크 대기열의 다음 안전 조회 기회로만 다시 확인합니다. 수동 링크가 정확한 SKU와 연결되어 활성화되면 해당 상품은 `high` 우선순위가 되며, 후속 GoldBox 응답에 포함될 때 먼저 갱신합니다.

Chrome 확장 프로그램은 `/api/collect`의 각 `items` 항목에 `productId`와 함께 현재 선택 옵션의 `itemId`, `vendorItemId`를 선택적으로 전송할 수 있습니다. 두 값이 모두 있으면 가신은 `productId:itemId:vendorItemId`를 정확 옵션 SKU로 저장하고, 동일한 상품 페이지라도 `vendorItemId`가 다른 옵션의 현재가·가격 이력·최저가를 섞지 않습니다. 확장 프로그램이 두 값을 보내지 못한 과거 관측값은 productId 단위의 레거시 관측값으로만 유지되므로, 옵션이 여러 개인 상품에서는 선택 옵션 URL의 쿼리 문자열에서 `itemId`와 `vendorItemId`를 읽어 함께 보내야 합니다.
