# 옵션별 가격 추적 데이터 계약

가신은 쿠팡 파트너스 API에서 제공하는 `productId`, 제휴 링크의 `itemId`와 `vendorItemId`, 상품명, 현재가를 사용합니다. 세 식별자가 제공되면 이를 결합한 키로 동일한 상위 상품 안의 용량·수량·구성 SKU를 별도 상품으로 저장합니다. 링크에 아이템 식별자가 없는 경우에는 링크 지문을 대체 식별자로 사용해 서로 다른 변형 옵션이 합쳐지지 않도록 처리합니다.

상품명에서 추출 가능한 `ml`, `L`, `g`, `kg`와 `개`, `팩`, `입`, `병`, `캔`, `봉`, `박스`, `세트`, `롤`, `매` 표기는 제품 목록과 상세 화면에 표시하며, 현재가를 10ml·100ml·100g 기준으로 환산합니다. 쿠팡 파트너스 응답에 색상·맛·규격을 별도 구조화 필드로 제공하지 않는 경우에는 원본 상품명에 포함된 구성만 표시합니다. 이 경우에도 아이템·판매자 아이템 식별자는 별도의 추적 키로 보존합니다.
